# WinUAE smoke cases for the out/C command set.
#
# One case per line:  Name | Command | Arguments
# Command is the C: file name. Arguments are passed verbatim after the redirections.
# "SKIP: reason" as the Arguments column records the command without running it.
#
# Every case runs as:  C:<Command> <NIL: >>SYS:smoke.log <Arguments>
# with @@BEGIN/@@END markers around it, so a hang or crash shows as a BEGIN
# without an END. Cases run in file order and may use files earlier cases made.
# RAM:smoke/ and SYS:smoke-input.txt are prepared before the first case.
