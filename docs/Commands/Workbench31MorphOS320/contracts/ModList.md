# ModList contract

Profile: `morphos320`. Goal step: CC18. Recorded: 2026-09-12.

The MorphOS 3.20 media contains `MorphOS/C/ModList` as version 50.4
(`13.6.05`), 2,798 bytes with SHA-256
`2b5ad54617a1104eef44ca182677d3a7dfdfa18b4dc1df2bf07090d954f9ece2`.
The corresponding source member is `c/modlist/modlist.c` in the official 3.20
C source archive; the extracted source is 4,954 bytes with SHA-256
`0e79768422b74ea0a39291e14673bc832d56850843c956651289e7e98ab18d32`.
The source accepts the `VERBOSE/S` switch through DOS `ReadArgs` (the parsed
value is not otherwise used), opens DOS 37, grows a public resident buffer in
4,096-byte then 2,048-byte steps, follows Exec's resident-module indirection
table under `Forbid`, snapshots resident fields, prints the address/name/
version/priority/flags table, derives revision from extended data or the ID
string, polls Ctrl-C after each row, and frees owned resources. The adapter
keeps the parser lease balanced even on the source allocation-failure return.

`src/Commands/Native/NativeMorphOSModListCommand.cs` implements the bounded
DOS/Exec body. The private resident root is
`tests/Commands.AddBuffersNativeRoot/NativeMorphOSModListEntry.cs`.

## Bounded native receipt

`tools/Commands/qualify_morphos_modlist_native_entry.ps1` compiles resident
68000/020/040 HUNKs and executes thirteen supplied DOS/Exec vectors per CPU (39
total): empty, one-resident and three-resident listings, ID-string revision parsing,
allocation failure, parser failure, Ctrl-C, missing DOS, Workbench and
entry-boundary rejection, and interleaved repeat calls. The durable receipt is
`artifacts/modlist-morphos-native-20260919-multinode-v2/qualification.json`.

Each HUNK has six reachable methods, no managed allocation sites, runtime
helpers, external native targets, exception regions, or fatal machine-fault
sites, and the fixture reports no leaked resources or shared-image writes.
The generated bytes preserve the source-visible table and flag ordering while
using the available native `VPrintf`/`FPuts` calls. This is adapter evidence
only: complete resident-table population, exact packed-binary/source
correspondence, original guest parity, PURE/resident reuse, package admission,
and differential comparison remain open. The AROS-derived source reference is
not a license grant for a shipping replacement; reuse and attribution review
remain open.
