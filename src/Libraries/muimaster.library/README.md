# muimaster.library

This directory is reserved for CopperOS's implementation of the Amiga MUI
(Magic User Interface) master library. It refers to Amiga MUI, not Material UI.

The implementation will be developed here as a source project. Its built runtime
library should eventually be staged as:

`filesystem/SYS/Libs/muimaster.library`

Implementation code and project files will be added later.
